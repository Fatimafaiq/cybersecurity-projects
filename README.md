# Cybersecurity Projects

Hands-on cybersecurity projects covering network security, defensive monitoring, web security, and cryptography — built to apply core security concepts through practical implementation rather than theory alone.

## Projects

| # | Project | Focus Area |
|---|---------|------------|
| 01 | [Port Scanner](./01-port-scanner) | Network reconnaissance — scans hosts for open ports and running services |
| 02 | [File Integrity Monitor](./02-file-integrity-monitor) | Defensive monitoring — detects unauthorized file changes using hashing |
| 03 | [Password Security Analyzer](./03-password-security-analyzer) | Cryptography/auth — evaluates password strength against common attack patterns |
| 04 | [Security Log Analyzer](./04-security-log-analyzer) | Defensive monitoring — parses and flags suspicious activity in log files |
| 05 | [Network Traffic Analyzer](./05-network-traffic-analyzer) | Network security — captures and inspects packet-level traffic |
| 06 | [Nmap Reconnaissance](./06-nmap-reconnaissance) | Network security — host/service discovery using Nmap |
| 07 | [Nmap Vulnerability Assessment](./07-nmap-vulnerability-assessment) | Vulnerability assessment — identifies known weaknesses via Nmap scripts |
| 08 | [Metasploit Exploitation Lab](./08-metasploit-exploitation-lab) | Offensive security — controlled exploitation lab using Metasploit Framework |

## Tools & Skills

- **Languages:** Python
- **Tools:** Nmap, Metasploit Framework, Wireshark
- **Concepts:** Network security, vulnerability assessment, defensive monitoring, log analysis, cryptography, password security

## About

These projects were built as part of hands-on cybersecurity practice, applying both offensive (reconnaissance, exploitation) and defensive (monitoring, log analysis) techniques in isolated lab environments.
